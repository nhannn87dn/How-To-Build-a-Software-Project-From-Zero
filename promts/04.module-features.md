Dưới đây là bộ prompt giai đoạn 5 - **Xây dựng một module tính năng**, gồm **một khối chung** (nạp ngữ cảnh) và **6 prompt** (5a đến 5f). Mỗi prompt bắt đầu bằng dòng `[DÁN KHỐI CHUNG VÀO ĐÂY]`: bạn copy khối chung bên dưới dán vào đúng chỗ đó. Cách này giúp bạn sửa quy tắc ở một nơi và dùng cho cả 6 prompt.

## Mục lục và thứ tự dùng (lặp lại cho từng module)

| Bước | Prompt | Việc chính | Kết quả |
|---|---|---|---|
| 1 | 5a Spec module | Bảng DB, API, quyền, quy tắc nghiệp vụ | `docs/specs/<module>.md` |
| 2 | 5b Migration và entity | Tạo bảng thật theo spec | Migration chạy được, entity/model |
| 3 | 5c Backend | Kiểm tra đầu vào, service, controller, phân quyền | API của module chạy được |
| 4 | 5d Test | Test cho logic quan trọng và luồng API | Test xanh |
| 5 | 5e Frontend | Trang và lớp gọi API (lặp lại cho từng giao diện) | Giao diện chạy trọn luồng |
| 6 | 5f Kiểm tra luồng và đóng module | Kiểm tra theo AC, bảo mật, cập nhật tài liệu, merge, chọn module kế | Module hoàn tất |

Mỗi module làm trên một nhánh tính năng tách từ `develop`, commit nhỏ sau mỗi bước chạy được, CI xanh mới merge.
